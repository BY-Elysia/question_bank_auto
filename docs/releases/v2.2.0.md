# 析页 v2.2 · 对话有据，题目可追溯

发布日期：2026-11-07。

AI 助手现在能够读懂你选择的教材资料。查找某一章的选择题、阅读完整解答、确认答案状态，或者直接围绕当前题目展开讨论，都可以在同一段对话中完成。

## 从题目开始，也从来源核对

- **选择对话资料**：为每段对话选择工作区，助手按选定范围查询。
- **向助手提问**：从完整题目进入对话，自动带入准确的题目定位。
- **结构化查题**：关键词、章节、题型与答案状态组合筛选，按需读取完整题干、选项、子题和解答。
- **可点击来源**：回答附带教材、题号、页码和修订信息，点击查看原图及来源框，再定位回教材。
- **明确答案身份**：区分教材答案、AI 生成和人工修改，标记待确认状态。
- **持续的对话体验**：沿用流式回答、插话、打断、主动询问、确认后继续与刷新恢复。

## 为后续 AI 能力建立边界

新增独立 catalog 查询模块，通过 `CatalogReader / QuestionIndex / AccessPolicy` 连接现有仓储。模型工具统一经过参数校验、账号权限、资料范围、调用预算和结果限额；业务服务不依赖 pi 或 SQLite。

派生索引按教材版本更新，查询时建立，无需在首页预加载全题库。来源证据与工具日志独立持久化，模型原始输出继续进入私有运行记录。规范化题目引用避免模型自行拼接题目地址，来源 ID 由服务端验证绑定。

当前采用单账号门禁、只读教材工具与关键词检索。数据库查询适配器、权限策略和后续搜索方式可以沿明确端口扩展；通用 SQL 与教材写入不作为模型工具开放。

## 升级

沿用现有数据卷、登录会话、教材、助手模型配置和 P0 对话。首次使用时创建知识索引与证据数据库，无需重新提取教材。
