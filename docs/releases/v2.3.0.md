# 析页 v2.3 · 看着教材，与 AI 一起校对

发布日期：2026-11-08。

在可视化页面选中一道题，直接告诉助手哪里需要处理。AI 可以读取原图、核对识别结果、修复题目或补全答案；修改完成后，题目立即更新，差异和撤销就在对话旁边。

- **留在当前教材**：内嵌助手复用完整聊天能力，支持流式回答、插话、停止和询问后继续。
- **以原图为依据**：按需读取选中题目的来源页与相邻页，正常预览图无需额外高清加载。
- **从建议走到执行**：明确的修复与补答案指令启动现有教材工作流，结果经版本校验后提交。
- **改动看得见、撤得回**：逐题记录修改前后内容，撤销保留其他题目的后续编辑；同题冲突不会被覆盖。
- **刷新也能接回进度**：模型步骤与后台任务分开持久化；关掉面板任务继续，重启后可从检查点恢复。

技术上保持 pi 轻量执行内核与自有 Harness，通过统一 ToolExecutor、后台任务端口、ReviewActions 和现有 ReviewService 连接界面与 Agent。业务操作、权限、模型协议、持久化和前端状态各自独立，保持后续扩展的接口边界。
