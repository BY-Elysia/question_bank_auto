# 析页 v2.1 · 对话随你推进

AI 助手现在可以边生成边交流。你可以补充要求、立即打断并调整方向，或把下一件事放入队列。需要决定时，助手会提出简短问题，等你选择或输入答案后继续。

- 流式显示回答，支持公式渲染。
- 插话、打断改向、完成后追加三种输入方式。
- 停止保留输出，失败可从检查点继续，也可重新生成。
- 结构化询问和确认卡片，刷新后保留等待状态。
- 会话重命名、删除和历史消息分页。
- SSE 断线回放、持久化队列、原始输出与 token 用量记录。

执行层采用 pi-agent-core / pi-ai 1.5.0，产品 Harness 独立管理会话、运行、工具交互、SQLite 事务和事件。模型协议、工具注册、上下文读取、存储和界面均通过明确接口连接，为下一版教材检索和数据库工具建立基础。

助手模型设置与教材保持独立。原有教材提取、逐题校对、补题和导出流程完整保留。

详细设计：[AI 助手 Harness](../assistant-harness.md)；接口：[后端接口清单](../backend-interface-inventory.md)。
