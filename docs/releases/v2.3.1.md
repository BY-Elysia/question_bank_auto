# 析页 v2.3.1 · 从教材对话，到可执行的校对

发布日期：2026-11-09。

选中一道题，告诉 AI 哪里需要处理。析页将教材查询、原图阅读、题目修复与答案生成接入同一个可视化工作台，让对话直接推动校对工作，结果可查看、可追溯、可撤销。

本次发布将 v2.1 至 v2.3.1 的助手能力与架构重构统一合入 main。

## 对话，跟得上你的思路

助手支持流式回答、随时停止、插话、打断改向与追加任务。遇到需要确认的问题，模型可以暂停询问，收到回答后继续。消息、运行状态与检查点持久保存，刷新页面或离开工作区后仍能接回进度。

## 让答案回到教材原文

选择本次对话可读取的教材，助手即可检索题目、阅读题干、选项与解答。引用绑定实际读取的题目、修订号和来源页，点击即可查看原图并定位题目。教材原答案、AI 生成答案与人工修改保持明确标记。

## 在题目旁完成修改

可视化页面内嵌完整聊天能力。助手按需查看选中题目的原图及相邻页，通过共享教材工作流修复公式、调整题目或补全缺失答案。修改自动回到页面，展示前后差异，并支持逐题撤销；其他题目的后续编辑得到保留。

## 为扩展建立清晰接口

- **轻量内核与自有 Harness**：pi 负责模型执行，应用管理持久运行、用户交互、后台任务和 SSE 事件。
- **业务能力独立**：`QuestionOperations` 提供启动、等待、取消、记录查询与撤销；审核应用层统一编排任务和候选提交。
- **权限与数据分离**：`ActionContext` 校验运行上下文，`WorkspaceAccess` 管理工作区访问，`CatalogQueries` 隔离查询实现。
- **图片适配独立**：`SourceImageReader` 定义模型图片输入，基础设施层负责正常预览图读取与编码。
- **前端按宿主组合**：独立聊天页与教材助手侧栏共用消息和输入视图，各自管理上下文与资源，侧栏不加载隐藏的历史列表和资料选择器。

本轮同时修正同一对话中多个任务的修改归属，以及教材删除后的取消行为。架构测试持续约束模块依赖方向，现有 HTTP 路由、教材存储格式及 v1.1 题库 JSON 导出保持兼容。

## 验证

140 项后端测试、39 个浏览器用例通过。服务器真实教材图片完成提取、原图读取、AI 修复、差异查看、刷新恢复与撤销验证；原有教材文档及修订号保持不变。
