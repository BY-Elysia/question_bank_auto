## 修复与回归

- Skill 调用记录保留结构校验失败的字段路径和错误类型，不记录原始模型输出。
- 批量提取连续结构校验失败后，降级为逐个完整范围提取。跨页题仍作为一个整体；保留 pending 排除；配额/网络错误不触发拆分；逐题结果必须精确匹配范围。
- 前端保留已有小问编号，避免 `( (1) )`；完整题号不再重复包成“第 习题2.1第2题 题”。
- 后端构建、OpenAPI 检查、类型检查及 50 项测试通过；前端构建与 5 项浏览器端测通过（自动测试使用替身模型，真实样本测试如上）。逐范围降级由新增自动测试覆盖；本次真实恢复使用原有重试取得合法输出，未把它误记成新降级路径的真实模型验证。

## 尚未满足的质量要求

- 部分证明步骤被模型压缩。例如第一章第 14 题虽然题干、分段公式和跨页来源正确，解释未逐句保留。当前结果不能称为逐字无损 JSON 化。
- 样本第一页从上一题证明中间开始，系统作为正文保留，没有单独生成“缺少题干”提示。
- 第一组只含章中/章末页，未从页眉恢复章节名。
- 人工对照为重点抽查，不能推导出全书公式识别准确率。

## 复现

先 `npm run build:all`。通过环境变量设置 MODEL_BASE_URL、MODEL_PROTOCOL、MODEL_NAME、MODEL_API_KEY；不要把密钥写入命令历史、仓库或报告。

- `LIVE_IMAGE_DIR=/absolute/path/pic1-5 node scripts/live-textbook-images.mjs`
- 失败后用输出的 root：`LIVE_WORKSPACE_ROOT=/absolute/test/root node scripts/live-image-resume.mjs`
- 合并成功后：`LIVE_WORKSPACE_ROOT=/absolute/test/root node scripts/live-image-review.mjs`

这些是显式、付费的真实模型测试，不进入默认 CI。恢复诊断脚本仅在本地测试目录保存原始返回，便于定位 JSON 语法问题。最后以工作区内容和导出核对结果为准，不覆盖保留首次失败报告。
