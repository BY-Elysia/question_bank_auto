# 前后端可维护性重构验证

本次检查重点为新增补题、教材信息编辑、个人中心和 AI 助手，以及其依赖的后台任务、仓储并发和浏览器资源状态。没有修改模型提示词、教材导出格式或历史数据。

## 重构内容

- 四处实体写锁复用 KeyedLock；三处后台执行管理复用 BackgroundTasks，保留各用例的持久化状态和恢复语义。
- 补题已提交结果的判定归 JobHandler，由补题处理器实现，不在任务恢复/异常处理里按 insert 硬编码。
- AssistantReply 从助手服务分离模型、上下文和用量编排；配置、用量、对话、上下文适配器可在组合入口注入。
- 六个教材基础字段共享组件与校验约束；修复共享表单标签可访问名称。
- 资源切换清除旧数据；新功能的 GET 支持取消；聊天草稿按对话隔离，配置自动刷新保留未保存编辑。
