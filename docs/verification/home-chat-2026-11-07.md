# 首页与独立助手配置验证

## 实测瓶颈与改动

优化前真实 Chrome 三个新浏览器上下文首次加载首页、等工作区卡片可见：4566 / 5485 / 5237 ms，中位数 5237 ms。工作区列表 GET 为 178–214 ms 量级；主要延迟来自入口脚本→登录检查→应用脚本→工作区请求的串行依赖。

HTML 开始解析即请求会话并预加载应用入口，登录组件复用同一 Promise；教材详情和上传框改为按需加载。应用包从约 222 kB 缩至约 158 kB（未压缩构建产物），首页不下载详情、上传、弹窗及公式模块。退出登录清除内存启动会话，不将授权状态存入持久缓存。

侧栏移除新建工作区，保留教材库新建与快捷键。助手改为历史列表、居中会话、底部输入区及欢迎页；支持 Enter/Shift+Enter 和中文输入法合成状态。原有后台回复和草稿隔离保留。

题库和助手分别持久化配置、实例化模型客户端和测试连通性。已有题库配置路径及 API 兼容；新增助手配置 API 三个端点，文档共 45 个端点。空配置没有跨用途密钥回退。
