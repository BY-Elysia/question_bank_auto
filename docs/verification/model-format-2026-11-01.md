## 修改内容

- 默认 Skill 首轮使用 text 模式，系统指令与当前请求都要求单个紧凑 JSON；保留本地 JSON、schema、来源和内容质量校验。失败时仍只有原来的第二次严格 schema 尝试，未提高重试次数或时限。
- 工作流提供可选 OutputContract，执行器只负责通用编码、校验、解码和再次校验，不识别题目业务。外部 REST/存储契约保持不变。
- 单题仅让模型生成 question/issues，单个正文/标题只生成 text/issues；key、空字段、原文答案的 source/pending 标记由后端确定。表格、图片及批次仍使用完整契约，保留所有小问、原解答及来源。
- 规划、跨页核对及单题答案的模型侧来源采用具名千分位整数 box。输入输出使用同一表示；通过校验后按固定比例转换为原有0–1坐标数组。非法矩形直接拒绝，不做小数点猜测修复。
- 更新 cross-page-reconcile 1.5.0、page-content-extract 1.3.0 的 Skill 指令；格式反馈只包含受限的字段错误，不把整段损坏输出再次塞给模型。原始输出依旧留在可选私有跟踪中。
