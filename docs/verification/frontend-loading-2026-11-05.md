# 前端加载审计与优化（2026-11-05）

## 实测发现

使用生产构建、隔离的真实 HTTP 后端和相同浏览器操作，分别记录首页→配置→提取→静置→编辑→隐藏→恢复的请求。模型用确定性替身，本次不调用真实模型。变化前后记录保存在忽略提交的 `workspace/diagnostics/frontend-loading-2026-11-05/before.json`、`after.json`。

| 场景 | 修改前 | 修改后 |
| --- | --- | --- |
| 首页停留 12.5 秒的列表 GET | 3 次 | 1 次 |
| 配置页停留 4.5 秒的工作区 GET | 3 次 | 1 次 |
| 完成后的工作区静置 12.5 秒 | 6 次工作区 GET + 1 次健康 GET | 0 次 |
| 保存一次编辑 | 1 次 PATCH + 1 次工作区 GET | 保持一致，立即刷新 |
| 页面隐藏 12.5 秒 | 6 次工作区 GET + 1 次健康 GET | 0 次 |
| 恢复可见 | 等下一次轮询 | 工作区/健康各刷新 1 次 |

隐藏状态测试通过 visibilitychange 模拟事件，另有离线恢复回归。12.5 秒窗口的 0 次不是永久停止：闲置状态仍每 30 秒更新，活动提取及核对/修复任务仍每 2 秒更新。列表活动时每 6 秒、闲置时每 30 秒；健康检查每 60 秒。

## 资源与数据

App（197,742 B）登录后加载；Review（414,672 B）、KaTeX CSS（29,802 B）及需要的字体进入核对/预览时加载。功能代码没有删除，完整操作流程的总 JS 体积基本不变；收益是避免在登录、上传和配置阶段提前下载/执行核对代码。CSS 与公式渲染仍处于同一异步边界，不回退到原始 LaTeX。

普通页面通过 `preview=omit` 省略重复整章预览，正式文档和章节进度保留；仅打开阶段预览时请求完整数据。API 默认 include，保持兼容。RichText 按文本值 memo，避免轮询、选中来源或改变画布宽度时重复执行相同 Markdown/公式解析。

## 请求生命周期

- 隐藏或离线取消读取及定时器，恢复后重新读取一次。
- 每个资源请求结束后才安排下一次；手动刷新连续触发时，合并为当前请求之后的一次读取，并丢弃写操作前可能过期的响应。
- 连续读取失败指数退避，最大 60 秒；手动重试立即执行。
- 不缓存写请求，不延迟编辑、提取或候选确认后的刷新，不修改教材数据或模型流程。
