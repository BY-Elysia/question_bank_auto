# 页图加载优化（2026-11-05）

截图对应「验证 · 数列跨页与公式」第 1 页。原始上传 JPEG 为 92,119 字节，统一后的 PNG 为 388,138 字节。旧画布直接加载 PNG，登录门禁默认给业务响应加 no-store，重复访问也要重新传输。

## 修改与边界

- 标准 PNG 仍用于模型、下载及 JSON/ZIP 来源引用。UI 默认使用最长边不超过 1400、quality 90 的 WebP 预览，放大至 100% 以上才加载全尺寸无损 WebP。
- 预览加载完成后只低优先级预读下一页；节流/2G 模式跳过。预览失败自动回退 PNG，高清失败保留预览并可单独重试，切页重置局部状态。尺寸提前占位，来源框只在图片就绪后显示。
- PageImagePort 定义变体；基础设施负责生成、磁盘缓存、同图并发合并、临时文件原子替换。源文件尺寸/时间变化产生新缓存键，内容修订不会重复编码页图。
- 图片响应使用 ETag 和 private, no-cache，允许字节缓存及 304；登录门禁仍先执行，未登录/退出后的条件请求返回 401/no-store。
- 既有 PNG API 默认行为保留；新增查询参数与 workspace 页图 URL 已同步到 OpenAPI。
