# 前端重建：析页教材工作台

本次新增独立的 React 前端，直接调用已有后端，覆盖 PDF / 图片上传、自动转图后的设置、章节分组、提取进度、原图校对、人工编辑、AI 修复、答案审核及导出。没有引入用户管理或题库功能。

## 视觉与交互

界面采用石墨灰底色、蓝青强调色、网格与局部柔光。首页教材插画由本地 CSS 绘制，不依赖外部图片或付费模板。Motion 用于页面、列表和真实处理进度的过渡；系统开启减少动态效果时禁用持续动画与大幅位移。进度来自后端，不使用计时器模拟完成率。

- 工作区首页：名称搜索、状态筛选、新建、继续处理。
- 上传弹窗：拖入文件、查看大小、调整图片上传顺序和移除；PDF 自动转图。
- 提取设置：保留旧版教材字段、答案策略，默认前缀缓存。
- 章节分组：逐张、多选、Shift 连选、按钮分配或拖入章节；未覆盖所有图片或存在空组时禁止提交。
- 处理页面：显示页数、章节进度、预览，取消后可刷新并恢复。
- 校对页面：章节目录、原图、内容三栏；页码与来源框双向联动，缩放、拖动画布、调整分栏宽度；移动端上下排列。
- 人工编辑：题干、选项、子问、答案及步骤，正文、表格与图注；保存使用 expectedRevision。
- AI 操作：核对、补答案、按要求修复。候选可查看修改前后、定位原文、接受或拒绝。
- 导出和版本：JSON、含页图的 ZIP、恢复历史修订、确认删除整个工作区。

## 技术与目录

React + TypeScript + Vite + Tailwind CSS + shadcn/ui + Radix + Motion。Markdown / LaTeX 使用 react-markdown 与 KaTeX；不渲染原始 HTML，提取文本中的 Markdown 图片不自动加载远端资源。复杂公式渲染和工作区页面拆分为延迟加载模块。

```text
client/
├── src/
│   ├── App.tsx                 # 导航、应用框架、连接状态
│   ├── lib/
│   │   ├── api.ts              # HTTP 与后端契约类型
│   │   ├── hooks.ts            # 可取消轮询、写操作互斥与错误状态
│   │   └── labels.ts          # 状态、内容类型及日期显示
│   ├── components/
│   │   ├── ui/                # shadcn Button / Dialog
│   │   ├── ContentBody.tsx     # 题目、子问、表格与答案
│   │   └── RichText.tsx        # Markdown / LaTeX
│   ├── features/              # 各业务页面和交互组件
│   └── styles/                # 按布局、业务页面拆分的主题样式
└── tests/                     # 隔离后端 + 浏览器端到端测试
```

前端类型直接引用后端契约的 type，不复制另一套数据模型；生产包不包含后端业务代码或 API 密钥。页面通过 lib 调用 API，通用组件不反向依赖业务页面。架构测试限制单个 TS/TSX 文件不超过 400 行；样式另按页面拆分。

轮询采用单次完成后再安排下一次，离开页面会中止请求，避免并发请求覆盖状态。所有写操作显示忙碌/失败状态；编辑和候选决定携带 revision，冲突由后端拒绝并提示刷新。活动任务期间禁用编辑与导出。客户端路由使用 URL hash，刷新和复制工作区链接均可恢复页面。

## 开发与部署

仓库根目录：

```bash
npm ci
npm --prefix client ci
npm run build:all
node --env-file=.env dist/app/apps/control-api/main.js
```

打开 http://127.0.0.1:5002 。后端同时托管 client/dist，生产环境同源访问，无需额外配置 CORS。未配置模型时仍能管理材料和工作区；模型调用继续读取后端 MODEL_* / ARK_* 环境变量。

开发时运行后端后，另开终端执行 `npm run dev:web`，访问 http://127.0.0.1:5173 。Vite 将 /api 代理到 5002，可通过 API_TARGET 覆盖。Dockerfile 已包含前端构建和静态资源复制，原 compose 入口保持 5002。

## 验证

```bash
npm run check
npm run build:web
# 安装测试浏览器（首次）
cd client && npx playwright install chromium && cd ..
npm run test:web
# 已安装 Google Chrome 时也可使用：
PW_BROWSER_CHANNEL=chrome npm run test:web
```

浏览器测试使用独立临时目录和真实 HTTP / PDF 转图 / 文件仓储 / 导出；模型返回由测试适配器提供，不调用付费服务，也不修改用户工作区。覆盖从上传到审核导出的完整流程，以及图片拖拽分章、取消/刷新/恢复、移动端、减少动画、键盘弹窗、网络失败重试。截图与失败追踪保存在 client/test-results（Git 忽略）。

本轮没有再次调用真实模型，外部模型链路沿用后端已有真实端测。没有执行 Docker 镜像构建验证；本地生产静态托管和浏览器完整流程已验证。当前提供深色主题；鉴权、用户容器调度、亮色主题不属于本次实现。

验证结果：46 项后端/架构测试通过，前端 TypeScript 与生产构建通过，5 项 Chrome 浏览器端到端测试通过。前端运行依赖审计为 0 项漏洞。KaTeX 的嵌套版本通过 overrides 与直接依赖统一，避免保留旧版依赖。
